# 本轮性能改造与验证

## 改造

- Astro 静态组件输出，不加载前端框架运行时；交互使用按页面分离的原生脚本。
- 主页不引用粒子数据、粒子绘制脚本或粒子原图，粒子功能通过 particles.html 访问。
- PNG 转为 WebP，首页 CG 使用 360px 缩略图，大图仅打开弹窗时请求。
- 音频 preload=none，播放由用户触发；网易云接口选择后请求，已获取歌单在内存中复用。
- 雨滴数量上限 110、涟漪数量上限 18、像素密度设上限、绘制节奏限制为 30 FPS；后台停止绘制及装饰动画。粒子离屏暂停，移动端减少粒子绘制数量。
- 图片设置宽高与异步解码，非主角图片延迟加载；导航与页脚启用 content-visibility。
- 生产构建压缩 HTML、CSS 与 JavaScript。

## 资源体积口径

scripts/baseline.json 保存改造前 HTML 直接引用的本地文件体积总和：16,560,565 字节。scripts/audit.py 对构建后 HTML 使用相同统计方式；结果保存在 scripts/performance-result.json。加入七张 CG 的缩略图后，主页当时约 0.53 MB，减少约 96.8%（AVIF 交付后的最新口径见下文“AVIF + PNG 交付”）。

此统计包含 HTML 中 src/href 引用的本地文件，不代表浏览器实际下载总量：不含后续按需加载的 CG 大图、音乐、备用动作、角落小人帧图（约76 KB），以及 CSS 内的鼠标文件。三个新动作约92–99 KB/张，三张新 CG 大图约250–288 KB/张，只有实际切换时加载；相册缩略图延迟加载。未测量网络加载时间、Lighthouse 分数或实际 FPS。最新精确值以 audit.py 输出为准。

## 功能验证

桌面四列导航、手机页面、日夜主题、独立页面跳转、粒子聚拢/散开、人物消息与 CG 弹窗；本地音频与网易云 37 首歌单的播放、切歌、进度及音量均通过浏览器操作检查。构建通过，本地静态引用完整，无合成雨声。

角落小人只在换帧时重绘，使用定时器代替持续全速绘制，动画帧图约129 KB；导出 GIF 约162 KB，页面不加载 GIF。GIF 共8帧、透明背景、192×208、循环播放，已核对文件结构。

唱片入口直接引用本地封面约35 KB（与展开面板复用同一文件），无需新的音乐库；旋转使用CSS动画，暂停状态停止旋转。

人物共五种动作、相册共七张 CG。已通过浏览器验证动作循环、图文对应、专属台词轮换、点击大图/缩略图/箭头切换、键盘切换与关闭、日夜主题以及手机窄屏布局。

字体使用本站托管的 Fredoka 拉丁字集（29,732 字节）及 Noto Sans SC 中文可变字重子集（502 字，135,280 字节），合计165,012字节。使用 font-display:swap，保持加载期间文字可读。此 CSS 内加载体积不计入上面的 HTML 直接引用口径；audit.py 单独记录 fontBytes。中文子集在本地生成，未发送站点文案到第三方服务。字体应用到主页、相册、音乐及独立粒子页面。

## 后续交互与绘制迭代

- 粒子闪烁使用1024项正弦表，指针离开时跳过距离计算，靠近时先以平方距离过滤。scripts/particle-cost.mjs 对实际渲染脚本进行运算计数：桌面13,744粒子每帧sin从13,794次降到50次；无指针时hypot从13,744次降到0次。模拟指针靠近时只有2,975次sqrt，粒子位移与原版一致。结果见scripts/particle-cost-result.json；这不是浏览器FPS或设备耗时测量。
- 相同尺寸不重建粒子或雨滴；尺寸变化按动画帧合并。浏览器缓存恢复页面时重新同步绘制，离开主页后暂停人物/明信片等装饰动画。
- 快速切歌会撤销上一首待播放状态，过期Promise不影响新歌曲；失效封面回退到本地图片。scripts/music-race.test.mjs 验证旧请求失败、新请求成功及封面回退。
- CG弹窗锁定背景滚动，缩略图只滚动自身容器。手机切图/关闭/音乐按钮最小44px，音乐来源选择字号16px；提高日间说明文字对比度。已检查320px手机宽度，弹窗切换及粒子散开/聚拢/暂停均正常。

## AVIF + PNG 交付（上线前整理）

- 全部内容图片改为 AVIF（优先）+ PNG（回退）双格式交付：页面用 `<picture>` 选择格式，动态图片（人物动作、CG、播放器封面、角落帧图）由脚本内置回退链处理；WebP 中间格式已移除。favicon/ICO/CUR 与矢量 SVG 保留原生格式。
- scripts/optimize-assets.mjs、scripts/optimize-new-characters.mjs 统一生成双格式，画质口径在 scripts/image-formats.mjs（大图 66 / 立绘 65 / 缩略图 62）；角落页内帧图改为优先加载 AVIF（约 76 KB），GIF 仍只作下载、页面不加载；音乐封面源文件保留在 assets/originals/music-cover.webp。
- scripts/audit.py 口径更新：directBytes 按支持 AVIF 的现代浏览器计算（HTML 引用的 AVIF 体积），新增 compatBytes（全 PNG 回退口径）与 AVIF/PNG 配对完整性校验，并检查 dist/assets 内不存在缺 PNG 回退的孤儿 AVIF。
- 本轮实测：主页 directBytes 429,954 字节（较改造前减少 97.4%），compatBytes 882,657 字节；粒子页 directBytes 709,637 字节；两页 AVIF/PNG 配对 13 组全部存在。
